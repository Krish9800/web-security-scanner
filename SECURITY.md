# Security Policy

## Responsible Disclosure & Authorized Use
The **Web Security Assessment Scanner (`webscan`)** is an educational, defensive security tool designed strictly for authorized penetration testing, vulnerability assessments, DevSecOps pipelines, and local laboratory environments.

### Authorized Testing Only
- You must **never** scan endpoints or infrastructure without explicit, documented permission from the system owner.
- The software incorporates safe, non-destructive probe methods and an allowlist-enforcing scope engine to prevent accidental out-of-scope testing.

## Reporting a Vulnerability
If you discover a vulnerability within this codebase:
1. Do **not** open a public issue.
2. Email the maintainers at `security@example.internal`.
3. Provide a clear description, reproduction steps, and potential remediation.
4. Maintainers will respond within 48 business hours with an acknowledgment and mitigation timeline.
